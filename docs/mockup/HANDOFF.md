# SmartSignal 개선 목업 — 구현 인수인계

`smartsignal-improved.html` 은 개요(overview) 화면의 다음 단계 개선안을 담은 **정적 목업**입니다.
실데이터·API 호출 없이 시드 고정 난수로 그럴듯한 시세를 그리며, 브라우저에서 파일을 바로 열면 됩니다.

## 보는 법

| 방법 | 설명 |
|---|---|
| 파일 더블클릭 | 다크 테마 + 개선 포인트 주석 켠 상태로 열림 |
| 우하단 `✎ 개선 포인트` 버튼 | 번호 뱃지·설명 패널 켬/끔 |
| 상단 달 아이콘 | 다크/라이트 전환 |
| URL 뒤에 `#light` | 라이트 테마로 열기 (스크린샷용) |
| URL 뒤에 `#clean` | 주석 숨긴 상태로 열기 · `#light,clean` 조합 가능 |

번호 뱃지(①~⑥)는 목업 전용 장치이며 본 구현에는 넣지 않습니다.

## 무엇이 달라지는가

기존 개요 화면의 문제의식: **판정("매수 우위")과 점수("14/22")는 보여주지만, 그 근거·맥락·과거 성적은
다른 화면에 흩어져 있거나 아예 없다.** 이번 개선은 "이 신호를 믿어도 되는가"에 답하는 정보를 개요 한 화면에 모은다.

### ① 시간대 합의 스트립 (히어로 하단)
- 15분·1시간·4시간·1일 네 시간대의 판정·점수를 나란히 표시. 현재 보는 시간대는 강조 테두리.
- 오른쪽에 요약 한 줄: "4개 중 3개 시간대가 매수 방향으로 정렬".
- 셀 클릭 시 해당 시간대로 전환(상단 segmented와 동일 동작)하면 좋음.
- **백엔드**: 시간대별 마지막 봉의 `signal`/`score`만 있으면 되므로, 대시보드 API에
  `mtf: [{interval, signal, score}]` 를 추가하거나 경량 엔드포인트(예: `GET /api/mtf-summary?symbol=…`)를 신설.
  캔들 전체를 4번 내려받는 방식은 피할 것(응답이 무거워짐). 서버에서 15m/1h/4h/1d 계산 후 요약만 반환.

### ② 점수 근거 체크리스트 (기존 게이지 카드 대체)
- "왜 매수 우위인가" — 충족 조건은 체크 + 획득 점수(+3/+2/+1), 미충족 조건은 회색 `0/3` 형식.
- 기본으로 충족 조건 전부 + 미충족 상위 2개를 보여주고, 나머지는 "더 보기"로 접기.
- 하단 안내문: 추세장/횡보장 감액(60%) 여부를 명시 — `scoring.py`의 `strong_trend` 분기 그대로.
- **백엔드**: `backend/scoring.py` `compute_signals()` 는 현재 합산 점수만 반환한다.
  마지막 봉에 대해 조건별 `{key, label, points, max, hit}` 목록을 함께 반환하도록 확장
  (buy_raw/sell_raw 를 만드는 각 `b(cond, pts)` 항이 그대로 목록의 행이 된다).
  조건 한글 라벨은 프론트가 아니라 백엔드 한 곳에서 관리할 것(스크리너·백테스트에서도 재사용).
- 기존 원형 게이지·매수/매도 막대는 이 카드로 흡수(점수 큰 숫자 14/22가 게이지 역할을 대신함).

### ③ 가격 사다리 (기존 "참고 수준" 목록형 대체)
- SL–진입–TP1–TP2 를 실제 가격 축 위에 점으로 배치. 진입~TP 구간은 초록, 진입~SL 구간은 빨강 띠.
- 손익비 필: `TP1 손익비 1:1.2`, `TP2 손익비 1:2.3`, `SL까지 −1.5%`.
- **계산**: 손익비 = (TP−진입)/(진입−SL). 값은 이미 대시보드 응답에 있는 TP/SL/진입가로 프론트에서 계산 가능.
- 축 스케일: `min(SL)−여유 ~ max(TP2)+여유` 를 0~100%로 정규화해 `left:%` 배치 (목업의 인라인 스타일 참고).
- 신호 없음(관망) 상태에서는 기존처럼 "신호가 발생한 경우에만 산출" 문구로 빈 상태 처리.

### ④ 최근 신호 성적 (신규 카드)
- 현재 종목·시간대의 최근 신호 20건을 **백테스트와 같은 규칙**(TP/SL/48봉 만료)으로 자동 채점.
- 상단 스탯 3개: TP 도달률, 신호당 평균 손익(수수료 차감), 성적이 가장 좋은 점수대.
- 표: 발생 시각 · 신호 · 점수 · 진입가 · 결과 태그(TP1/TP2 도달·SL 이탈·48봉 만료·진행 중) · 손익.
- **백엔드**: `backend/backtest.py` 로직을 재사용해 `GET /api/signal-track?symbol=…&interval=…` 신설.
  기본 파라미터는 백테스트 화면 기본값(7점, 48봉, 수수료 0.1%)과 일치시켜 두 화면의 숫자가 어긋나지 않게 한다.
- 행 클릭 시 신호 장부 화면의 해당 봉으로 이동하면 좋음(기존 `data-view="ledger"` 전환 + 스크롤).

### ⑤ 관심종목 라이브 행 (사이드바)
- 각 행에 현재가 · 24시간 등락(색) · 미니 스파크라인(24포인트) · 신호 뱃지(`매수`/`매도`, 5점 이상일 때만).
- **백엔드**: `GET /api/watchlist-quotes` 일괄 엔드포인트 신설(종목별 현재가·등락률·종가 24개·신호 요약).
  종목마다 개별 호출하면 무료 시세 API 한도를 즉시 소진하므로 반드시 일괄 + 서버 캐시(1~5분)로.
- 갱신 주기는 느슨하게(1~5분). 실패한 종목은 시세 칸만 `—` 로 두고 행 자체는 유지.

### ⑥ 신호 알림 벨 (상단 바)
- 관심종목에서 새 신호(5점 이상)가 발생하면 벨에 붉은 점. 클릭하면 최근 알림 드롭다운(목업에는 드롭다운 미포함).
- 1차 구현은 **폴링으로 충분**: ⑤의 watchlist-quotes 응답에 신호 요약이 이미 있으므로,
  "직전 응답에 없던 신호"를 프론트에서 감지해 점을 켜면 된다. 웹소켓·푸시는 다음 단계.
- 읽음 처리는 localStorage(비로그인) / 계정 저장(로그인) — 계정 모델은 `backend/auth.py` 참고.

### 그대로 유지 (목업에서 생략)
지표 타일 4개(ADX·RSI·OBV·Range Filter), 관측 카드(FILTER OBSERVATION), 신호 장부·스크리너·백테스트·표시 설정
화면, 종목 팔레트(Ctrl+K)·패턴 빌더·계정 모달은 변경 없음. 목업은 개요 화면의 달라지는 부분만 담았다.

## 디자인 규칙

- **토큰**: 목업의 CSS 변수는 `frontend/styles.css` 와 이름·값이 동일하다. 컴포넌트를 옮길 때 색상 하드코딩 금지 —
  전부 기존 토큰으로 해결된다. 새로 추가된 클래스: `.mtf-*`, `.evi-*`, `.ladder*`, `.rr-*`, `.hist-*`, `.oc-tag`,
  `.sig-tag`, `.watch-price`, `.watch-spark`, `.bell-dot`.
- **다크 기본**: bare `:root` 가 다크, `[data-theme="light"]` 만 라이트 덮어쓰기 — 기존 방침 그대로.
- **차트 팔레트 검증**: 동시에 그려지는 시리즈 조합(EMA·VWAP·RF)은 dataviz 검증 스크립트로 확인 완료 —
  다크(#0D1519 표면) 전 항목 PASS, 라이트는 CVD 분리 7.3(허용 하한 6~8 구간)이라 **이중 부호화가 필수**:
  목업처럼 선 끝에 EMA/VWAP/RF 직접 라벨을 반드시 함께 그릴 것. RF(파랑)와 FBB(보라)는 동시 표시 시
  정상 시력 기준 분리(ΔE 12.7)가 미달이므로, 두 레이어를 동시에 켜는 조합은 피하거나 FBB를 점선으로 구분.
- **상태색 규칙**: `--bull`/`--bear`/`--warn` 은 결과 태그·등락·신호에만. 시리즈 색(`--s-*`)과 섞지 않는다.
- **숫자는 전부 `--mono` + `tabular-nums`** — 기존 관례 유지.

## 구현 순서 제안

1. ② 점수 근거 체크리스트 — 백엔드 확장(조건별 내역)이 선행 조건이며 파급이 가장 큼(신뢰의 핵심).
2. ③ 가격 사다리 — 프론트만으로 가능, 반나절 거리.
3. ① MTF 스트립 — 경량 엔드포인트 1개 + 프론트.
4. ④ 신호 성적 — backtest.py 재사용 + 새 엔드포인트.
5. ⑤ 관심종목 라이브 + ⑥ 알림 — 일괄 시세 엔드포인트가 공통 기반이므로 묶어서.

## 열어둔 질문

- ④의 채점 기본값(7점·48봉·0.1%)을 사용자가 백테스트 화면에서 바꾸면 개요 카드도 따라가게 할지,
  개요는 항상 기본값 고정으로 둘지.
- ⑤의 시세 갱신 주기 — 무료 API 한도(특히 국내주식)와 트레이드오프. 시장별로 다르게 둘 수도 있음.
- ②에서 매도 근거도 함께 보여줄지(현재 목업은 우세 방향만). 관망 상태일 때는 양쪽 상위 3개씩 제안.
